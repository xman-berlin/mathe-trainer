## Findings

### Bugs & Correctness

1. **Local `ng build` / `ng test` abort on Node 25** — process exits 134 (SIGABRT) right after `Building...`. CI matrix is 22.x/24.x; deploy workflow still uses **20.x**. No `.nvmrc` / `engines` field → easy footgun for contributors.
2. **Word-problem feedback path bypasses `ExerciseStateService`** — uses raw `setTimeout` for advance delays (`word-problem-exercise.component.ts:150-155`) while other exercises share `handleResult`. Risk of divergent timing / uncleared timers on destroy.

### Technical Debt

3. **3 open TODOs** (unchanged since March):
   - `services/stats.service.ts:664` — badge notification (Phase 5)
   - `services/daily-streak.service.ts:262-265` — streak celebration UI
4. **`MasteryData` unused export** — `models/stats.model.ts:63` (only definition, never imported).
5. **Deploy Node mismatch** — `.github/workflows/deploy.yml` uses Node `20.x`; CI + AGENTS.md use 22/24.

### Code Duplication

6. **Identical `getTypeLabel` / `getTypeIcon` maps** in:
   - `services/clock.ts:114-145`
   - `components/set-clock-exercise/set-clock-exercise.ts:145-171`
   `clock-exercise` already delegates to `ClockService`; set-clock should too.
7. **Template method calls in `@for` loops** — `getTypeIcon(type)` / `getTypeLabel(type)` in clock + set-clock templates; `gameService.getTimesPlayed(...)` in all 4 game templates + global achievements. Prefer maps/computed or pure pipes.

### Dead Code

8. Unused `MasteryData` type (see #4).

### Missing Tests

9. **No unit specs for games**: `balloon-pop`, `breakout`, `dino-run`, `flappy-fox`, `base-game.component`.
10. **No unit spec for `services/clock.ts`** (problem generation + labels).
11. **No E2E click-through to game routes** (`spielen/flappy-fox`, etc.) — navigation only toggles the Spiele tab on achievements; AGENTS.md requires every new route to have a click-through test.

### Architecture Issues

12. **God files** (grew since March):
    - `supabase.service.ts`: **938** lines (was 880)
    - `badge.service.ts`: **709** (was 665)
    - `stats.service.ts`: **697** (was 619)
13. **No route-level lazy loading** — `app.routes.ts` eagerly imports every feature (math, clock, deutsch, 4 games). Primary driver of initial bundle size.
14. **Games still large despite base class**: balloon-pop 467, breakout 385, dino-run 364, flappy-fox 328 lines.

### Security

15. **✅ No `innerHTML` / `bypassSecurityTrust` / `eval`**.
16. **✅ Anon key in `environment*.ts` is expected** (public); no service-role key in frontend.
17. **`npm audit`: 36 vulnerabilities (1 critical, 26 high, 8 moderate, 1 low)** — notably:
    - Angular packages **&lt; 20.3.25/26** XSS / DoS advisories (project is on **20.3.18**)
    - `@angular/build` / vite / tar / ws transitive highs
    - **Prod deps alone**: 7 high (Angular + `ws`)
18. **Username-only auth** (kids app) — intentional, but any device with the site can impersonate a listed user. Document threat model; consider PIN for shared devices if needed.

### Performance

19. **Initial bundle over budget** (last known Jul 12 artifact): `main` ~500KB + large chunk ~332KB (likely Supabase) vs warning budget 500KB / error 1MB.
20. **Component styles over 12KB budget** (source SCSS bytes):
    - `clock-exercise.scss` ~24KB
    - `exercise.component.scss` ~24KB
    - `set-clock-exercise.scss` ~17KB

### Dependencies

21. **Angular 20 → 21** available (major); within 20.x, patch bump to **≥20.3.26** should clear several CVEs without a major migration.
22. Tooling majors available: eslint 10, typescript-eslint 8.68, angular-eslint 22, Playwright 1.62.
23. No `engines` / `.nvmrc` pinning Node to CI-supported LTS.
